台股題材新聞儀表板 v3｜使用說明

這版新增三個重點：
1. 題材熱度分數
2. 你的持股／關注股影響表
3. 盤前操作提醒與來源可信度分級

一、正確打開方式
請用 Google Chrome 或 Microsoft Edge 打開：
tw_stock_news_dashboard_v3.html

不要用 Cool File Viewer、Internet Explorer 或檔案預覽器，否則可能跳指令碼錯誤。

二、更新新聞方式 Windows
方法 A：
直接雙擊 run_update_windows.bat

方法 B：
在資料夾內開 PowerShell，執行：
python fetch_news.py

抓最近兩天、每題材最多 12 則：
python fetch_news.py --days 2 --max 12

三、頁面區塊
1. 今日焦點結論
   會顯示偏多、偏空或震盪輪動。

2. 盤前操作提醒
   提醒今天觀察順序，例如是否要先看台積電、台幣、散熱、PCB、電源等。

3. 你的持股／關注股影響表
   內建持有股：
   2308 台達電、2327 國巨、2330 台積電、3017 奇鋐、3044 健鼎、3324 雙鴻

   內建關注股：
   7769 鴻勁、2360 致茂、4958 臻鼎-KY、5347 世界

4. 題材熱度排行
   題材包含：
   焦點大事、AI 半導體／先進封裝、散熱、光通訊／CPO、PCB／CCL、被動元件、電源／電力管理、記憶體、金融、生技。

5. 焦點大事與分類新聞
   每則新聞會顯示事件、觀點、來源可信度與關聯股票。

四、來源可信度
A_官方：證交所、期交所、央行、公開資訊觀測站、公司公告等
B_主流財經：中央社、經濟日報、工商時報、鉅亨、MoneyDJ、Reuters 等
C_參考：其他新聞或轉載來源

五、手機自動更新
手機本機 HTML 不能穩定背景執行 Python。
如果你要每天早上手機直接看最新資料，建議下一步使用 GitHub Actions + GitHub Pages。
本壓縮包已附 .github/workflows/update-news.yml，可供自動排程使用。

六、重要提醒
台指期夜盤、8:30 試撮、台幣匯率、即時股價與成交量，仍要以期交所、央行、證交所與券商 App 交叉確認。
本工具是新聞整理與決策輔助，不構成投資建議。
